# 🏦 G-BANK — Digital Banking Platform

G-BANK is a modern full-stack digital banking application designed to provide a simple, secure, and user-friendly banking experience.

The platform includes two major interfaces:

### 👤 Customer Window
Customers can:
- Securely log in and register
- View account balance and financial insights
- Deposit, withdraw, and transfer money
- Track recent transactions
- Download transaction statements as PDF
- Email transaction reports
- Manage savings goals
- View upcoming bills
- Calculate EMIs and loans
- Manage personal profile information
- Change passwords and manage account security

### 🛡️ Admin Window
Administrators can:
- View total customers
- Monitor bank accounts
- View account balances
- Manage customer information
- Monitor loans
- Search users and accounts
- Export customer/account data
- Track banking statistics through an admin dashboard

## 🚀 Tech Stack

- **Frontend:** React.js
- **Backend:** FastAPI / Python
- **Database:** MongoDB Atlas
- **API:** REST API
- **Frontend Deployment:** Vercel
- **Backend Deployment:** Render
